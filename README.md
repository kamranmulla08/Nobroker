\# NoBroker Clone



A property rental and sale platform inspired by NoBroker. The project allows property owners to list properties and buyers or tenants to browse listings, express interest, and communicate with owners.



\## Technologies Used



\* \*\*Backend:\*\* Python, Django, Django REST Framework

\* \*\*Frontend:\*\* React, Vite

\* \*\*Database:\*\* PostgreSQL

\* \*\*Real-time Chat:\*\* Django Channels, WebSockets, Redis



\## Project Structure



\* `NoBrokerCloneNew/` — Django backend

\* `nobroker-frontend/` — React frontend



\## Features



\* User registration and login with Owner and Buyer/Tenant roles

\* Property listing, editing, and deletion

\* Property image uploads

\* Property browsing and details

\* Interest requests and owner responses

\* Owner and buyer dashboards

\* Real-time chat between users

\* Deal management



\## Local Development



The backend and frontend are maintained in separate folders. Refer to their respective configuration files and dependencies to set up the development environment.
